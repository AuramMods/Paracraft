# Paracraft 1.1.0

For **Minecraft 1.20.1 / Forge 47.4.28+ (47.x)**, using **Java 17**. Install `paracraft-forge-1.20.1-1.1.0.jar` on both the server and every connecting client, replacing the older Paracraft JAR.

## Changes since 1.0.0

- **Explicit villager trading:** agents can inspect native merchant offers and avatar-specific discounts, then buy or sell using carried main-inventory/offhand items. Native stock, payments, XP, stats, protection hooks, partial results, pause/restoration, and acquired-item delivery apply. Trading never starts as idle behavior. Wandering traders are supported through the same native merchant interface.
- **OpenRouter and compatible API endpoints:** configure the API base URL, optional API key, and exact Light/Planning model IDs in **K → Accounts → OpenRouter** or `/paracraft link openrouter`. Local Ollama can use `http://localhost:11434/v1` with a blank key and an installed tool-capable model. Endpoint changes isolate saved credentials and usage; failures do not fall back to another provider.
- **Agent continuity and fewer redundant decisions:** bounded prior decisions, actual tool arguments/results, saved task requests, and concise next-step notes accompany fresh snapshots. Mechanical work continues without routine model polling, with chat/events/status changes waking the agent. Planning handles task continuations directly; empty decisions retain unresolved requests.
- **Thinking/Planning visibility:** inference takes priority in the activity line. Idle wandering and automatic bed/food approaches pause while the agent thinks or plans, including the escalation interval. Passive looks, explicit movement, and survival reactions continue.
- **Native interaction actions:** agents can right-click blocks/entities and use held items, including offhand/sneaking gestures, precise hit points, and timed eating/drinking/bow use through native callbacks and Forge hooks.
- **Nearest block searches:** query actual nearby block IDs/tags, request the nearest N positions, and optionally limit radius. Results report distances, counts, and incomplete coverage.
- **Unequip and drop items:** agents can remove worn/held equipment and drop existing belongings, preserving native restrictions, stack metadata, and exact acquired-item ledgers.

## Build and validation

Built and reobfuscated locally with ForgeGradle. **No GitHub Actions** were used. Assets include the production JAR and `SHA256SUMS`; test classes and fixtures are excluded from the mod JAR.

The current feature set passes **126 unit tests and all 148 native headless Minecraft GameTests**. This includes nine native merchant scenarios covering discounts/inspection without purchases, real two-item/offhand payments, XP/stats/hooks, exact delivery, stock exhaustion, NBT and payment conservation, protection/busy sessions, checkpoint/request deduplication, native overflow, changed offers, and wandering-trader sales. Local API HTTP tests verify configured URLs, optional authentication, private persistence, cancellation, and credential/usage isolation.

No graphical client, authentication browser, paid inference, or actual Ollama model was launched for this release. Earlier live Luna checks remain documented in the repository. In-game visuals, natural-language trading/local-model behavior, and broader modpack compatibility remain manual checks. This release targets Forge 1.20.1; Fabric, NeoForge, and other Minecraft versions remain future work.
