# Paracraft 1.2.0

Install `paracraft-forge-1.20.1-1.2.0.jar` on the server and every connecting client. This release targets **Minecraft 1.20.1** with **Forge 47.4.28 or later in the 47.x series** and **Java 17**.

## What's new

- **Faster replies and fewer model turns.** Light restates a clear instruction in chat before Planning starts. The model can request context by section, batch read-only requests, and run one-shot programs without creating a task. The next decision receives compact recent-action history, exact search positions, and partial results.
- **Building and mining.** Agents can sample terrain in 8³ or 16³ cubes and build from compact layer layouts. The server finds reachable positions for mining, placing, and picking up drops. Placement batches continue past unreachable cells and report their coordinates.
- **Navigation and Creative mode.** Avatars use stairs, ladders, and hand-operated doors, gates, and trapdoors. They can swim to submerged destinations and fly automatically when allowed. Creative avatars can use items from the visible creative tabs.
- **Automatic equipment and combat.** Avatars select mining tools and melee weapons from carried inventory. They equip and use shields in both requested combat and reactive defense, then collect drops from defeated targets. They restore their held item after eating. Explicit equipment and right-click actions can select items directly into either hand.
- **Nighttime idle lighting.** An avatar with no tasks or available bed can hold a carried light in its offhand. Dynamic illumination comes from an installed client lighting mod.
- **Local API connectivity.** OpenAI-compatible endpoints on localhost can retry the other loopback address after a connection refusal. The client reports connection errors and shows upstream OpenRouter rejection details when provided.

## Build and validation

The production JAR was built and reobfuscated locally with ForgeGradle. The release includes `SHA256SUMS` for the JAR.

The build passed **156 unit tests and 165 headless Forge GameTests**. The suite covers acknowledgment ordering, navigation, building, mining, equipment conservation, native shield blocking, and idle light swaps.
