# Paracraft 1.0.0

First release for **Minecraft 1.20.1 / Forge 47.4.28+ (47.x)**, using **Java 17**. Install `paracraft-forge-1.20.1-1.0.0.jar` on both the server and every connecting client.

## Companions and the decision harness

- Server-owned survival avatars with inventories, equipment, health, hunger, death/respawn, beds, and saved state across owner reconnects.
- Client-owned ChatGPT sign-in with `/paracraft link chatgpt` or **K → Accounts**. Credentials stay on the player's computer. A labeled simulator is available without sign-in.
- Configurable Light/planning routes, defaulting to Luna `none` / `xhigh`, with snapshots, persistent tasks/memory, strict typed decisions, and interruptible action programs.
- Server-executed travel, following, inventory search/collection/delivery, mining, farming, combat, equipment, internal 2×2 and table 3×3 crafting, explicit portals, and native commands where permitted.
- Walking/sprinting navigation that preserves builds by default and opens wooden doors/fence gates. Automatic terrain recovery is a separate server opt-in.
- Default ambient idling: brief glances, local walking around a fixed sixteen-block resting area, nighttime beds, and safe food restocking. It consumes no extra model decisions and can be toggled by the agent.
- Owner controls, delegated chat instructions, and name-free chat when exactly one nearby avatar is authorized. Configurable admission defaults to four saved avatars per owner and 64 active per server.

## Controls and visibility

- Press **K** for companion controls, model routes, account linking, and daily reported token totals with Luna API cost estimates.
- Public nameplates show current activity and task counts when looking at an avatar.
- Agent-output debugging is configurable and defaults off in installed worlds; Gradle launches enable it for development.
- Actual ChatGPT plan limits are available through **Manage usage**. The current integration does not expose a remaining-percentage readout, and API estimates are not subscription charges.

## Build and validation

The release JAR was built and reobfuscated locally with ForgeGradle. No GitHub Actions were used. The release includes the JAR and its SHA-256 checksum; QA classes and fixtures are excluded from the mod artifact.

Validation: **93 unit tests and 112 native headless GameTests**, plus earlier live Luna delivery/crafting checks and daily token-accounting verification. No graphical client or browser was launched for the release build.

Native client rendering/UI flows and broader modpack compatibility still need manual verification. Fabric, NeoForge, other Minecraft versions, and specialized storage/movement integrations are not included in this release. Daily token history begins when the daily tracker was introduced; older lifetime totals cannot be assigned to individual days.
